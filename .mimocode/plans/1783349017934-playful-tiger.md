# Camera Enable/Disable Toggle — Implementation Plan

## Goal

Add per-camera enable/disable functionality with a slide toggler widget in the sidebar camera list. Disabled cameras stop their GStreamer pipeline, show "DISABLED" in grid/flex layouts, and skip reconnection attempts.

## Files to Modify (7 files)

### 1. `src/ui/sidebar/types.rs`

- Add `pub enabled: bool` to `CameraInfo` (default `true`)
- Add `CameraStatus::Disabled` variant with label `"DISABLED"`
- Add `CameraToggled(usize, bool)` to sidebar `Message` enum

### 2. `src/ui/app.rs`

- Add `pub camera_enabled: Vec<bool>` field to `App`
- Initialize all to `true` in `new_app()`
- Set `enabled: true` in each `CameraInfo`

### 3. `src/ui/update.rs`

**`update_sidebar()` — handle `CameraToggled(idx, enabled)`:**
- Set `app.camera_enabled[idx] = enabled`
- Set `app.sidebar.cameras[idx].enabled = enabled`
- If disabling: call `bridge.stop()`, tear down audio pipeline, set status to `Disabled`
- If enabling: call `bridge.start_from_config()` to restart the pipeline

**`update_frame()` — skip disabled cameras:**
- Add `if !app.camera_enabled[i] { continue; }` at the top of the per-camera loop to prevent reconnection attempts and frame processing for disabled cameras

### 4. `src/ui/sidebar/view.rs`

Replace the camera row structure. Currently each row is a single `button` containing the entire row. Restructure to:

```
row![
    button(row![dot, name_column, stats]).on_press(CameraClicked(idx)),  // selectable area
    toggler(cam.enabled).on_toggle(|v| CameraToggled(idx, v)),          // slide toggle
]
```

Use `iced::widget::toggler` (Iced 0.13 API):
```rust
iced::widget::toggler(cam.enabled)
    .on_toggle(move |v| Message::CameraToggled(row_idx, v))
    .size(14)
    .width(iced::Length::Fixed(36.0))
    .style(move |_theme, _status| iced::widget::toggler::Style {
        background: if cam.enabled {
            iced::Color::from_rgb(0.2, 0.8, 0.2)  // green when on
        } else {
            iced::Color::from_rgb(0.4, 0.4, 0.4)  // gray when off
        },
        foreground: iced::Color::from_rgb(1.0, 1.0, 1.0),
        ..iced::widget::toggler::Style::default()
    })
```

When disabled: show gray dot color and "disabled" stats text.

### 5. `src/ui/view/grid_layout.rs`

Add `is_disabled` check. For disabled cameras, show a "DISABLED" placeholder (like OFFLINE but with muted gray and different label):
```rust
let is_disabled = !app.camera_enabled.get(idx).copied().unwrap_or(true);
```
Show `"DISABLED"` label with a muted color when `is_disabled` is true.

### 6. `src/ui/view/flex_layout.rs`

- Skip disabled cameras in the thumbnail strip (don't render thumbnails for disabled cameras)
- If the main camera is disabled, show a "DISABLED" placeholder in the main view area

### 7. `src/infrastructure/reconnect.rs`

Add a `reset()` method to `ReconnectState`:
```rust
pub fn reset(&self) {
    self.fps_zero_since.set(None);
}
```

## Implementation Order

1. `reconnect.rs` — add `reset()` (small, no dependencies)
2. `sidebar/types.rs` — add `enabled`, `Disabled`, `CameraToggled`
3. `app.rs` — add `camera_enabled` Vec
4. `update.rs` — handle toggle + guard reconnect
5. `sidebar/view.rs` — add toggler widget
6. `view/grid_layout.rs` — handle disabled in grid
7. `view/flex_layout.rs` — handle disabled in flex
