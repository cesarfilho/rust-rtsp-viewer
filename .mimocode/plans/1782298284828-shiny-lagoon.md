## Implementation Plan

### Phase 1: Fix Freezing (GStreamerBridge + VideoWidget)

**File: `src/iced_app/gstreamer_bridge.rs`**

1. **Replace `Arc<Mutex<Option<Vec<u8>>>>` with double-buffer swap**:
   - Add `frame_generation: Arc<AtomicU64>` counter
   - Appsink callback writes to a staging buffer, then atomically swaps pointer
   - `latest_frame()` reads without cloning: return `Option<(Arc<Vec<u8>>, u32, u32, u64)>` where u64 is generation
   - Add `fn has_new_frame(&self, last_gen: u64) -> bool` to avoid unnecessary work

2. **Remove outer `Mutex` from `GStreamerBridge`**: The `frame_buffer` and `frame_size` already have their own `Arc<Mutex>`. The outer lock is unnecessary for reads.

**File: `src/iced_app/video_widget.rs`**

3. **Store last generation number** in `VideoWidget`. In `view()`, only clone/rebuild Handle when generation changed.

**File: `src/iced_app/mod.rs`**

4. **`FrameUpdate` handler**: Update `last_frame_gen: Vec<u64>` per camera. Only trigger view rebuild if any camera has new frame.

### Phase 2: Add Live Metrics to GStreamerBridge

**File: `src/iced_app/gstreamer_bridge.rs`**

5. **Add lightweight metrics inside `GStreamerBridge`**:
   - `frame_count: AtomicU64` (incremented in appsink callback)
   - `last_fps_calc: Instant` + `fps_snapshot: f64` (calculate FPS every 500ms from frame_count delta)
   - `pipeline_state: Arc<Mutex<gst::State>>` (read via bus watch for error/state-change monitoring)
   - Bus watch on pipeline to detect errors → set camera status to `Offline`/`Reconnecting`

**File: `src/iced_app/sidebar.rs`**

6. **`CameraInfo` fields become mutable** via `Arc<Mutex<Vec<CameraInfo>>>` or just update the Vec in `App`.

**File: `src/iced_app/mod.rs`**

7. **`FrameUpdate` handler**: For each camera, read `bridge.fps_snapshot()`, `bridge.pipeline_state()` and update `sidebar.cameras[idx]` accordingly.

### Phase 3: Implement Audio Pipeline

**File: `src/iced_app/mod.rs`**

8. **Add to `App` struct**: `audio_pipelines: Vec<Option<gst::Pipeline>>` (one per camera).

9. **`Message::ToggleAudio`**: When turning on, call `build_audio_pipeline_for_url()` from `infrastructure::audio.rs`. Store pipeline. When turning off, set to `Null` and drop. Need to wrap in `Rc<RefCell>` since pipelines aren't `Send`.

**File: `src/iced_app/gstreamer_bridge.rs`**

10. **Audio pipelines can't live in `GStreamerBridge`** (not `Send`). Store them in `App` via `Rc<RefCell<Option<gst::Pipeline>>>`. The `build_audio_pipeline` function in `infrastructure/audio.rs` already handles pipeline construction.

### Phase 4: Implement Diagnostics Tab

**File: `src/iced_app/sidebar.rs`**

11. **Diagnostics tab**: Add `diagnostics: Vec<Hint>` to `Sidebar`. In the Diagnostics view, render each hint with severity glyph + metric + cause text, colored by severity.

**File: `src/iced_app/mod.rs`**

12. **`FrameUpdate`**: For selected camera, create a lightweight `Metrics` snapshot from the bridge's atomic counters, call `diagnostics::diagnose(&snapshot)`, store result in `sidebar.diagnostics`.

### Phase 5: Implement Snapshot + Recording (stub)

**File: `src/iced_app/mod.rs`**

13. **Snapshot**: Use `SnapshotWriter` from `infrastructure::snapshot_writer.rs`. Extract frame from bridge, write PNG.

14. **Recording**: Use `RecordingSession` from `infrastructure/recording.rs`. Start/stop filesink on the GStreamer pipeline.

### Phase 6: Minor Fixes

15. `CycleSidebarTab` should also set `sidebar.visible = true`
16. Grid calc should subtract toolbar (~36px) + status bar (~24px) from height
17. `Enter` key → `SelectCamera` (not fullscreen)
18. Sidebar border width → use `1.0` instead of `Border::default().width`
19. Pipeline start errors → update camera status to `Offline` with error message
20. Remove `Sidebar::new()` with hardcoded test data (dead code)
