# Refatoração UI: Separação por Entidades

## Objetivo
Separar `ui/mod.rs` (978 linhas) em arquivos menores por entidade/funcionalidade, respeitando as camadas da arquitetura.

```

├── mod.rs            978 linhas  ← App, Message, view, run, subscription, new_app
├── update.rs         423 linhas  ← update() + handlers
├── state.rs          148 linhas  ← BackoffState, Toast, ContextMenu
├── gstreamer_bridge.rs 1355 linhas ← pipeline + appsink
├── sidebar.rs        756 linhas  ← sidebar + metrics
```

## Entidades a Extrair

### 1. `app.rs` — Estado da Aplicação
Conteúdo:
- `pub struct App` (25 campos)
- `fn new_app()` (inicialização)
- `pub(crate) const TOOLBAR_HEIGHT/STATUS_BAR_HEIGHT/QUICK_ACTIONS_HEIGHT`

Dependências: `GStreamerBridge`, `VideoWidget`, `Sidebar`, `Theme`, `AudioState`, `ReconnectState`, `AudioLevelState`

### 2. `message.rs` — Eventos
Conteúdo:
- `pub enum Message` (20 variantes)
- `pub enum LayoutMode` + `impl LayoutMode`

Dependências: `Theme`, `sidebar::Message`

### 3. `subscription.rs` — Assinaturas
Conteúdo:
- `fn subscription()` (teclado + resize + tick)

Dependências: `App`, `Message`

### 4. `view.rs` — Renderização
Conteúdo:
- `fn view()` (função principal)
- `fn view_toolbar()`
- `fn view_quick_actions()`
- `fn view_grid()` + `fn build_grid_cell()` + `fn build_offline_cell()` + `fn build_video_cell()` + `fn build_audio_badge()`
- `fn view_flex()`
- `fn view_status_bar()`
- `fn view_help_overlay()`
- `fn view_toast_overlay()`
- `fn view_context_menu_overlay()`
- `fn button_style()`

Dependências: `App`, `Message`, `Theme`, `LayoutMode`, `grid`, `sidebar`
